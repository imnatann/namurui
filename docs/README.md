## The short version

Every item is **one self-contained `.tsx` file**:

- `"use client"` on line 1.
- Imports from `"react"` only: no Tailwind, no animation library, no icon package.
- Props type exported with a `/** */` on every field.
- One `<style href>` naming the item, as the first child, e.g.
  `<style href="ui-<slug>" precedence="default">{css}</style>`; React 19 hoists and dedupes it, so
  N instances cost one stylesheet. Screens use `ui-screen-<slug>`, six items use a `-clean` suffix
  (`ai-answer`, `dropzone`, `memory-panel`, `stepper-form`, `thinking-state`, `toaster`), and
  `tool-call-card` uses `ui-tool-call`.
- `const css = /* css */ \`…\`;` at the bottom of the file.
- 176 of the 181 declare colours, durations and sizes as prefixed custom properties on the root
  class, so a host can re-skin one component without touching the page; `empty-calendar`,
  `enrichment-orbit`, `lead-sourcing`, `tab-overload` and `outreach-branches` declare none.
- One `:where(.dark, [data-theme="dark"])` block in 180 of the 181 files, and one
  `@media (prefers-reduced-motion: reduce)` block in 176; neither position within the sheet is
  fixed. `project-flow` is the one item that themes through a component-scoped
  `.ui-pf[data-theme="light"|"dark"]` mechanism instead, faithfully to the extracted original, and
  `frost-cloud`, `glow-cloud`, `lead-sourcing` and `model-wheel` handle reduced motion in
  JavaScript.

Copy the file you want into your project. Nothing else is required.

## What each document is for

- **Debating a colour or a curve?** `motion.md` and `theming.md` state the decision and the
  measurement behind it.
- **Integrating a component?** `catalogue.md` has the props table for the one you want.
- **Wondering how faithful this is?** `rea-rebuild.md` separates what is still byte-exact (the
  extraction step, the class names, the layout rules) from what was re-themed to NamurUI (colour
  values and timing functions), and from what is reconstructed (the behaviour). `method.md`
  covers the first pass and the MIT corpus measurements.
- **Shipping to real users?** `accessibility.md` gives the honest contrast figures, the
  opt-in AA layer, and what was not tested.

## Where the 181 files are

`src/namurui/` holds 181 component files and 181 demos, one demo per component. `src/styles/`
holds four stylesheets.

```
src/namurui/<slug>.tsx          the component, 181 of them
src/namurui/demos/<slug>.tsx    a zero-prop demo the gallery mounts, one per component
src/styles/tokens.css           the Ember token sheet
src/styles/motion.css           the motion token sheet
src/styles/gallery.css          gallery chrome
src/styles/high-contrast.css    the generated opt-in contrast layer
```

`src/gallery/registry.ts` discovers the components and their demos with `import.meta.glob`, so a
new file appears in the gallery with no registry edit.
